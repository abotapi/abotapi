## How to Use

Every scraper below runs on [Apify](https://apify.com/?utm_source=github&utm_medium=profile&utm_campaign=awesome-scrapers). Open one, enter a search or URL, and click **Start**.
You can also call it from code:

```python
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("abotapi/realestate-au-scraper").call(run_input={
    "mode": "location",
    "locations": [{"suburb": "Sydney", "state": "NSW"}],
    "maxListings": 20,
}, logger=None)
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
```

- **[Crawlee](https://github.com/apify/crawlee)** - Node.js/Python crawling library with browser and HTTP crawlers
- **[Playwright](https://github.com/microsoft/playwright)** - Headless browser automation for JavaScript-heavy sites
- **[Beautiful Soup](https://www.crummy.com/software/BeautifulSoup/)** - The classic Python HTML parser
- **[httpx](https://github.com/encode/httpx)** - Modern async HTTP client for Python
- **[apify-client (Python)](https://github.com/apify/apify-client-python)** - Run any scraper in this list from Python
- **[apify-client (JS)](https://github.com/apify/apify-client-js)** - Run any scraper in this list from Node.js
